### 🚀 Featured Projects

#### 🧠 Neural Fortress — agentic "Second Brain"

> **Stack:** Python · FastAPI · PostgreSQL + pgvector · Gemini · async ingestion

Personal knowledge service that ingests documents and conversations, embeds them into pgvector, and serves agentic retrieval over a FastAPI endpoint. Presented at **Melbourne Python (Jun 2026)** covering retrieval design, prompt routing, evaluation, and the cost/latency tradeoffs of running an agent loop in production.

---

#### 📍 LocalPulse — community signals on Google Cloud

> **Stack:** Gemini · Google Cloud · Python backend · Next.js

Hackathon build at the **Google Melbourne office** for the GDG × Google DeepMind AI Sprint. Selected as a **Top 9 finalist**. Owned the backend service, Gemini integration, and deployment pipeline in a one-day team sprint.

---

#### ⚙️ OptiShift — after-hours workforce dispatch (PoC)

> **Stack:** FastAPI · SQLite · ChromaDB · Vue 3 / Vite · Gemini 1.5 Flash

Two-layer architecture replacing manual after-hours dispatch: a deterministic **Hard Logic Layer** (SQLite, visa-compliance filtering) feeds a **Soft Logic Layer** (ChromaDB RAG + Gemini) that ranks candidate suggestions. Designed for explainability — every hard constraint is traceable to a rule, soft suggestions are always rerankable.

---

#### 👴 Elder Care Connect — senior wellness platform

> **Stack:** Vue 3 · FastAPI / Firebase · Bootstrap · PrimeVue · Vite · Mapbox

University capstone (FIT5032). Auth-aware home, animated hero, stats strip, feature grid, and map-based service lookup. Shipped a full home-page rewrite plus a pre-existing duplicate-header bug fix.

---

#### 🤖 AI Assignment Planner — n8n workshop

> **Stack:** n8n · Telegram Bot · Google Gemini · Google Calendar

Live workshop I co-facilitated for ~30 University of Melbourne students (Quantum Club × AWS Cloud Club). Telegram bot accepts an assignment PDF, Gemini decomposes it into subtasks, and events are written to Google Calendar. Shipped with student handouts, importable workflow JSON, facilitator guide, and sample assignment PDFs.
